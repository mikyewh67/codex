# Source map used for the trainer

The trainer was scoped to **Accounting 1, Test #1, Chapters 1–2**.

- `Analyzing and Recording Transactions(1).docx` — three-step transaction analysis, transaction families, debit/credit rules, journal format.
- `The Accounting Process(2).docx` — accounting cycle, journal → ledger → trial balance, financial-statement order.
- `Buckeye Company Instructions*.docx` — full-cycle assignment structure and transaction set.
- `Chapter Three Notes, Adjusting Entries*.docx` — reviewed for scope only; intentionally excluded from the Test #1 trainer because it is Chapter 3 material.

## Test material

- Supplied Test #1 practice test prompt — 15 questions, 31 points, 120 minutes.
- `Acctg 1, Test #1, Practice Test, Answers (1).docx` — official solutions, equations, normal balances, financial-statement calculations, and journal-entry answers.

## Handwritten notes

The uploaded notebook photos were used to preserve the student's own memory rules, especially:

- Debit-normal: Assets, Withdrawals, Expenses.
- Credit-normal: Liabilities, Capital, Revenue.
- If an account increases, use its normal-balance side; if it decreases, use the opposite side.
- The recurring workflow: financial position → accounts → recording plan → journalize.

The original source files and images are **not included** in the repository or app.
